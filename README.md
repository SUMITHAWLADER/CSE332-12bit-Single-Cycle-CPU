# CSE332 12-bit Single-Cycle CPU

A 12-bit Single-Cycle CPU designed and implemented as part of the CSE332: Computer Organization and Architecture course at North South University.

## Project Overview

This project focuses on the design and implementation of a custom 12-bit Single-Cycle CPU.

The project includes:

- Custom Instruction Set Architecture (ISA)
- CPU datapath implementation
- Control unit
- Register file
- ALU
- Memory operations
- Branch and jump instructions
- Input/Output operations
- Java-based assembler
- Logisim circuit implementation

## Project Files

- `Assembler.java` — Java-based assembler
- `CSE332-12bit-CPU.circ` — Logisim CPU implementation
- `ISA-Design-Report.pdf` — ISA and project documentation
